# Venkatesh Gorla — Modern Portfolio

## Files
- `index.html` — portfolio structure/content
- `style.css` — responsive dark UI
- `script.js` — navigation, reveal animations, active section and scroll progress
- `images/` — profile, internship, and credential images
- `resume.pdf` — put your resume here

## GitHub Pages
Replace the corresponding files in your existing `MY-PORTFOLIO` repository and commit/push them. Keep the repository's current Pages settings.

## Before publishing
1. Add or replace your profile photo inside `images/`.
2. Add your resume as `resume.pdf`.
3. Replace the LinkedIn placeholder URL in `index.html` with your actual profile URL.
4. If you have live project URLs, add them to the project cards.


## Theme selector
The navbar includes Dark, Light, and System modes. The selected mode is saved in the browser using localStorage.
